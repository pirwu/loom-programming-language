# LOOM

![Loom-Logo](img/loomlogo.png)

Компилируемый язык программирования с ассемблероподобным синтаксисом, статической типизацией и прямой компиляцией в машинный код x86-64.

Текущая версия: **1.26.10**

## О языке

LOOM задуман как язык, которого достаточно для собственного бутстрапа. Первая версия компилятора написана на Python 3.14.4, генерирует объектные файлы PE/COFF напрямую и линкуется через MinGW gcc. В версии **2.хх.хх** компилятор и линкер планируется переписать на самом LOOM.

Синтаксис намеренно низкоуровневый — ассемблероподобный three-address code со структурированными блоками. Управление памятью ручное. Скрытых аллокаций, приведений типов и вызовов нет.

## Пример

```loom
module main

import console

struct Point {
    x: i64
    y: i64
}

fn fib(n: i64) -> i64 {
    if n < 2 {
        ret n
    }
    a: i64 = fib(n - 1)
    b: i64 = fib(n - 2)
    ret a + b
}

fn main() -> i64 {
    p: Point
    p.x = 10
    p.y = 20
    console.print_int(p.x + p.y)
    console.print("\n")
    console.print_int(fib(20))
    console.print("\n")
    ret 0
}
```

## Быстрый старт

Требования:

- Windows 10 или 11, x86-64
- MinGW-w64 gcc в `PATH`
- Python 3.10+ (только если запускаешь компилятор из исходников)

Запуск компилятора из исходников:

```text
git clone https://github.com/pirwu/loom-programming-language
cd loom
python -m loomc tests/arith.loom -o arith
arith.exe
```

Запуск собранного `loom.exe`:

```text
loom tests/arith.loom -o arith
arith.exe
```

## Что поддерживается

Языковые конструкции:

- Модули, `import`, `export`, многофайловая сборка с префиксацией символов
- Функции, рекурсия, `extern fn`
- Переменные, глобальные переменные (`let`)
- Примитивные типы: `i8`..`i64`, `u8`..`u64`, `bool`
- Указатели `ptr<T>`, взятие адреса `&`, разыменование `*`
- Структуры `struct` с C-совместимым layout
- Перечисления `enum`
- Константы `const`
- Массивы `[N]T` на стеке, индексация `p[i]`
- Динамическая память: `alloc`, `free`, `realloc`
- Управляющие конструкции: `if`, `else`, `while`, `loop`, `break`, `continue`
- Метки и `jmp`
- Операторы: `+ - * / %`, `& | ^ ~ << >>`, `== != < <= > >=`, `&& || !`
- Приведение типов через `as`, `sizeof(T)`

Стандартные функции:

- Модуль `console`: `print`, `print_int`, `print_char`, `eprint`
- `alloc` / `free` / `realloc`
- `strlen` / `strcmp` / `strncmp`

## Что не поддерживается в 1.26.10

- Generics
- Сборщик мусора
- Замыкания и лямбды
- Вывод типов
- Перегрузка функций и операторов
- Макросы
- Обработка исключений
- Асинхронность
- Строки как встроенный тип (только `ptr<u8>` плюс длина)
- Проверка границ массивов в рантайме
- Метки циклов
- Экспорт структур и `enum` между модулями

## Производительность

Бенчмарк `fib(40)` — 331 миллион вызовов функций.

```text
cpp        0.4734s   (0.99x)
c          0.4782s   (1.00x)
loom       2.4919s   (5.21x)
nodejs     2.6305s   (5.50x)
python    37.7501s   (78.95x)
```

LOOM v1.26.10 не делает никаких оптимизаций: все переменные живут на стеке, нет регистрового распределения, нет инлайнинга. 
Результат — отставание от C в 5 раз и обгон Node.js на рекурсивной нагрузке.

Компилятор не использует LLVM и ассемблер. PE/COFF объектные файлы генерируются вручную, финальная линковка выполняется через MinGW gcc, который подтягивает CRT.
